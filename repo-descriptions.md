## Project focus

### `SG-CUBE-Camera-Model`

**Area:** Artificial Intelligence · Computer Vision · Multimodal AI

Combines real-time vision capabilities with Gemini Live, OCR, face recognition,
object detection, memory, safety assistance and accessibility-focused features.

### `smart-finance-supabase`

**Area:** Full-Stack Development · Finance · Backend

Personal finance application focused on expense and salary tracking with
Supabase authentication, PostgreSQL data and secure application data handling.

### `SmartCart-Analytics-AI`

**Area:** Machine Learning · Data Analytics · Customer Segmentation

Uses clustering techniques including K-Means and Agglomerative Clustering
to explore customer behavior and generate useful business insights.

### `Text-Summarizer-Web-Application`

**Area:** NLP · Artificial Intelligence · Web Development

A text summarization application designed to reduce lengthy content into
clearer and more concise summaries while retaining important information.

### `CliffWalking_-SARSA-Q_Learning-game`

**Area:** Reinforcement Learning · Algorithms · Game Development

Interactive environment for understanding and experimenting with
SARSA and Q-Learning reinforcement-learning strategies.

### `DSA_leetcode-journey`

**Area:** DSA · Algorithms · Interview Preparation

A continuous collection of Python solutions covering data structures,
algorithms and LeetCode problem-solving patterns.
